# 오늘의 자유수영 — 기능 스펙 개요

> 이미 만들어져 돌아가는 기능을 **코드 기준으로 거꾸로 정리한** 스펙이다. "원래 이렇게 동작해야 한다"의 기준 문서로 쓴다.
> 작성 2026-09-28 · 기준 커밋 `d30cd8c`
> 코드와 이 문서가 다르면 **코드가 사실**이다. 고칠 때는 둘 다 고친다.

## 1. 사이트가 하는 일 (3가지)

| # | 기능 | 사용자 | 문서 |
|---|------|--------|------|
| 1 | **성남 자유수영 시간표** + 매일 자동 점검 | 사이트 방문자 (점검은 운영자) | [스펙-01-성남-자유수영.md](스펙-01-성남-자유수영.md) |
| 2 | **한강 야외수영장** 안내 (여름 시즌) | 사이트 방문자 | [스펙-02-한강-수영장.md](스펙-02-한강-수영장.md) |
| 3 | **강습 신청 일정 모니터링** (금곡) | 운영자 본인 (텔레그램) | [스펙-03-강습-신청-알림.md](스펙-03-강습-신청-알림.md) |

1·2는 공개 웹 페이지, 3은 화면 없이 텔레그램으로만 동작한다. 1의 "매일 점검"도 운영자용 텔레그램 알림이다.

## 2. 전체 구조

```
[방문자 브라우저] ── swim.andlife.app (Vercel, main push 시 자동 배포)
   index.html  : 성남 화면 + 한강 화면 + 피드백 + 홈 화면 추가 (한 파일, 서버 없음)
   data/hangang-pools.js : 한강 데이터

[운영자 맥] ── launchd가 정해진 시각에 GitHub 워크플로를 "즉시 실행"으로 트리거
   08:00  lesson-alert.yml     → 강습 알림(아침)
   19:00  lesson-alert.yml     → 강습 알림(저녁)
   21:00  update-schedule.yml  → 시간표 크롤 + 공지 감시 + 공휴일 점검 + 강습 전날 예고 + 텔레그램
   (07:58·18:58·20:58 맥 자동 깨우기)
   실행은 맥의 self-hosted 러너(라벨 seongnam-mac)에서 한다.

[텔레그램 봇 "Today Swim"] ← 모든 알림의 도착지 (운영자 1인 채팅)
(점검은 알림만 한다. index.html 반영은 항상 사람이 직접 — 2026-09-28 GitHub 이슈·/confirm 자동 반영 폐지)
```

### 왜 맥에서 도는가
- 해외(GitHub 호스팅) IP에서 `spo.isdc.co.kr` 접속이 간헐적으로 통째로 막힘 → 국내 IP인 맥 러너로 옮김.
- GitHub 예약(cron)은 4시간 넘게 밀린 적이 있음 → 시각은 맥 launchd가 잡고 `workflow_dispatch`로 즉시 실행.
- 세부: [scripts/mac/README.md](../scripts/mac/README.md)

## 4. 세 기능 공통 요소 (3가지 기능 밖이지만 같이 돈다)

이 문서의 주 범위는 아니지만 세 기능과 얽혀 있어 요약해 둔다.

| 요소 | 요약 | 위치 |
|------|------|------|
| 정식 도메인 리다이렉트 | 공개 도메인이 `swim.andlife.app`이 아니면 그리로 이동. localhost·사설 IP·`file://`·점 없는 호스트는 예외 | `index.html` 상단 스크립트 |
| GA4 계측 | `G-S45MTX2JXK`. `?notrack=1` 또는 푸터 "오늘의 자유수영" 5번 탭(1.5초 이내 연속)으로 이 기기 추적 끔/켬(`localStorage.sw_notrack`) | `index.html` |
| 피드백 | 푸터 버튼 → 바텀시트. 탭 2개(잘못된 정보 / 불편한 점), 스크린샷 1장(긴 변 1600px·JPEG 82%로 축소), 익명 POST → Apps Script(시트 누적 + 메일). 전송 실패해도 완료 화면 | `index.html`, `scripts/feedback.gs` |
| 홈 화면에 추가 | iOS·안드로이드 브라우저에서 2번째·5번째 방문 때 7초 뒤 안내 시트. 안드로이드는 설치 버튼. 설치 실행(standalone) 시 우하단 새로고침 버튼 | `index.html`, `manifest.webmanifest`, `sw.js`(캐시 없음) |
| 최신성 | 1분마다 목록 다시 그림(월별보기 제외), 앱 복귀 시 날짜가 바뀌었으면 "오늘"로 리셋 | `index.html` |
| 운영자 대시보드 | 로컬 전용 `admin.html`(비공개) + `scripts/ga4-proxy.gs` | 저장소 밖 |

## 5. 외부 의존 / 비밀값

| 이름 | 쓰는 곳 | 없으면 |
|------|---------|--------|
| `TELEGRAM_BOT_TOKEN`, `TELEGRAM_CHAT_ID` | 모든 텔레그램 알림 | 알림 발송 실패 |
| `ANTHROPIC_API_KEY` (+선택 `ANTHROPIC_WORKSPACE_ID`) | 공지 해석·원본 검증 (Sonnet 5) | "링크만 보내는 무료 모드"로 강등 |
| `HOLIDAY_API_KEY` | data.go.kr 특일정보(공휴일 점검) | 공휴일 점검 건너뜀 |
| `SEO_CHANGES_CSV_URL` | 월말 TO-DO 변경사항 시트, `change-log.js` 기록 | TO-DO에 "미연동" 문구 |
| 맥 로컬 도구 | python3(pypdfium2·pdfplumber·pyhwp), swiftc | 해당 형식 첨부만 건너뜀 |
| 맥 상태 파일 | `~/.swim-notice/state.json`(공지), `lesson-state.json`(강습), `trigger.log` | 없으면 첫 실행처럼 동작 |

## 6. 문서 공통 용어

- **공사**: 성남도시개발공사 (`spo.isdc.co.kr`) 수영장 6곳.
- **유스센터**: 성남시청소년청년재단 (`snyouth.or.kr`) 수영장 4곳.
- **분당올림픽**: 한국체육산업개발 운영 분당올림픽스포츠센터 (`ksponco.or.kr`).
- **슬롯**: 자유수영 한 타임(`'HH:MM~HH:MM'`).
- **휴관 / 미운영 / 임시휴장**: 사이트 표시 구분. 스펙-01 §3 참고.
- **KST**: 서버·스크립트 날짜 계산은 모두 한국 시각. 단 **웹 화면은 방문자 기기 시각**을 쓴다.
