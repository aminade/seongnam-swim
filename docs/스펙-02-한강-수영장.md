# 스펙 02 — 한강 야외수영장

> 기준 커밋 `d30cd8c` (2026-09-28). 개요: [스펙-00-개요.md](스펙-00-개요.md)

## 1. 목적

여름 시즌(6~8월)에만 여는 **서울 한강공원 야외수영장·물놀이장 6곳**의 기간·운영시간·요금·수심·예약 방법을 한 페이지로 보여준다.
성남 자유수영 사이트 방문자가 여름에 "한강도 가볼까"를 바로 판단할 수 있게 하는 **시즌 한정 부가 페이지**다.

### 성공 기준
- 시즌 중 첫 화면에서 한강 페이지로 한 번에 들어갈 수 있다.
- 시설별 수심·야간 개장 여부·예약 방법(네이버 예약)을 펼치지 않고도 알 수 있다.

### 범위 밖
- 날짜별 운영 여부 계산(시즌 중 휴무가 없으므로 모든 시설을 항상 "운영"으로 표시).
- 자동 점검·크롤링(공식 사이트가 JS 렌더링이라 불가) — **매 시즌 사람이 직접 갱신**.
- 실시간 혼잡도, 날씨·우천 중단 알림.

## 2. 진입과 노출 기간

| 항목 | 규칙 |
|------|------|
| 진입 버튼 | 성남 화면 히어로 우상단의 둥근 떠다니는 버튼 "한강 야외수영장 · SUMMER OPEN →" |
| 노출 시작 | `HANGANG_COMMON.season.open` 당일부터 (2026: 6/19) |
| 노출 종료 | **폐장일이 속한 해의 9/15까지** (폐장 8/30 뒤 약 2주 더 노출 — 코드에 고정) |
| 기간 밖 | 버튼 숨김. 한강 페이지로 갈 방법 없음 |
| 데이터 로드 실패 | `HANGANG_COMMON`이 없으면 버튼 숨김 |
| 날짜 기준 | 방문자 기기 날짜 |

### 화면 전환
- 버튼을 누르면 성남 화면을 숨기고 한강 화면을 보여 주며 맨 위로 스크롤(짧은 등장 애니메이션). URL은 바뀌지 않는다.
- 한강 화면 왼쪽 위 `← 오늘의 자유수영`으로 돌아감.
- 새로 열거나 뒤로/앞으로 가기(bfcache 복원)로 돌아오면 **항상 성남 화면으로 시작**.

## 3. 데이터 (`data/hangang-pools.js`)

`index.html`이 `<script src="data/hangang-pools.js?v=…">`로 읽는다. **파일을 고치면 `?v=` 값을 바꿔야** 브라우저 캐시가 갱신된다. Node에서도 `module.exports`로 불러올 수 있다.

### 3.1 공통 `HANGANG_COMMON`
| 필드 | 2026 값 | 화면 사용 |
|------|---------|-----------|
| `season.open` / `close` | 2026-06-19 / 2026-08-30 | 기간 표시, 노출 기간 계산 |
| `season.note` | 휴무 없음, 폭우 시 일시 중단 | (화면 문구는 HTML에 따로 고정) |
| `restBreaks` | 매시 15분 휴식, 점심 12~13시, 저녁 17:30~19시 | (펼침의 휴식 시간은 코드에 고정값) |
| `price.pool` | 성인 5,000 · 청소년 4,000 · 어린이 3,000 | 수영장(type=pool) 요금 |
| `price.play` | 성인 3,000 · 청소년 2,000 · 어린이 1,000 | 물놀이장(type=play) 요금 |
| `price.free` / `discount`, `ban`, `ticketing`, `closingBuffer`, `confidence`, `source` | – | **화면 미사용**(기록용) |

### 3.2 시설 `HANGANG_POOLS` (6곳, 배열 순서 = 화면 순서)
| id | 이름 | 유형 | 지역 | 최대 수심 | 야간 |
|----|------|------|------|-----------|------|
| `ddukseom` | 뚝섬 한강공원 수영장 | pool | 광진구 자양동 | 1.2m | ○ |
| `yeouido` | 여의도 한강공원 수영장 | pool | 영등포구 여의도동 | 1.2m | ○ |
| `jamsil` | 잠실 한강공원 물놀이장 | play | 송파구 잠실동 | 1.0m | ○ |
| `gwangnaru` | 광나루 한강공원 물놀이장 | play | 광진구 광장동 | 1.0m | × |
| `yanghwa` | 양화 한강공원 물놀이장 | play | 영등포구 양화동 | 0.8m | × |
| `nanji` | 난지 한강공원 물놀이장 | play | 마포구 상암동 | 1.0m | ○ |

시설 필드:
| 필드 | 의미 | 화면 사용 |
|------|------|-----------|
| `name`, `area`, `type` | 이름·지역·요금 구분 | ○ |
| `depth.max`, `depth.items[{name,value}]` | 최대 수심, 풀별 수심 | ○ (items가 비면 "최대 N" 한 줄) |
| `hours.day` / `night` / `nightAvailable` | 주간·야간 시간, 야간 여부 | ○ |
| `hours.nightFrom` | 야간 시작일(2026-07-03) | **미사용** — 야간은 시즌 내내 운영하는 것처럼 표시됨 |
| `naverReservation`, `naverPlaceId` | 네이버 예약 가능 여부, 네이버 지도 장소 id | ○ |
| `url` | 공식 페이지 | **미사용** |
| `locker`, `parasol`, `sunbed`, `foodPolicy`, `alcoholPolicy`, `confidence` | 부가 정보(출처 포함) | **미사용**(추후 확장용) |

값을 못 찾은 항목은 `null` + `note`에 사유를 남긴다. 잠원은 2028년 이후 재개장 예정이라 제외.

## 4. 화면 스펙

### 4.1 레이아웃 (위→아래)
1. **히어로**: 한강 사진(`assets/hangang-4c.webp`), 제목 "2026 한강 야외수영장"(연도는 HTML 고정), 뒤로 버튼.
2. **공통 정보**
   - 기간: `M.D – M.D` + "휴무 없음"
   - 주간: 첫 번째 시설의 `hours.day`를 `9시 - 18시` 형식으로 (모든 시설 주간이 같다는 전제)
   - 야간: 야간 시설이 있으면 첫 야간 시설의 시간 + `(뚝섬·여의도·잠실·난지)` 식 이름 목록, 없으면 "미운영"
   - 이용 수칙 목록(HTML 고정 문구 5줄): 휴식·마감 시간, 수영복·모자, 대형 튜브·보조용품 금지, 다회용기만·배달·주류 금지, 폭우 시 중단
3. **시설 목록** (6행)
4. **푸터**: "한강 수영장/물놀이장 6곳 · …" + 출처 hangang.seoul.go.kr (피드백 버튼 없음)

### 4.2 시설 행
- 항상 초록 점(시즌 중 운영 가정).
- 이름 + 메타 `지역 · 수심 N · 야간 개장(해당 시)`.
- 우측 버튼
  - `naverReservation=true` → 초록 **"네이버 예약"** → `https://map.naver.com/p/entry/place/<naverPlaceId>` 새 창. (네이버 통합 예약 URL은 로그인 화면부터 떠서 쓰지 않음.)
  - false → 회색 "현장 구매"(링크 아님).
  - 버튼을 눌러도 행은 펼쳐지지 않는다.
- 행 머리를 누르면 펼침/접힘(시설별 기억, 성남 화면과 별개).

### 4.3 펼침 내용
| 줄 | 내용 |
|----|------|
| 운영 시간 알약 | `주간 시작 – 종료` (야간 시설은 종료가 야간 종료 22:00) |
| 휴식 | 점심시간 12:00–13:00 / (야간 시설만) 저녁시간 17:30–19:00 / 물놀이 종료 `종료 30분 전–종료` |
| 수심 | 풀별 `이름 값` 목록, 없으면 `수심 최대 N` |
| 요금 | `성인 N · 청소년 N · 어린이 N` (pool/play 요금표) |

### 4.4 계측 (GA4)
- 진입 시 가상 페이지뷰 `page_view` (page_title `한강 야외수영장 - Swim, Seongnam`, page_location `…#hangang`). 진입 버튼 모양이 바뀌어도 집계가 이어지도록 페이지뷰로 센다.
- 시설 펼침 `hangang_pool_<id>`, 네이버 예약 클릭 `hangang_book_<id>`, 뒤로 `hangang_back`.

## 6. 알려진 한계·위험

1. **연도·수칙·휴식 시간이 HTML·코드에 고정** — 데이터 파일만 바꾸면 제목 연도, 수칙 문구, 점심·저녁 휴식 시간은 그대로 남는다.
2. **야간 시작일 미반영** — 개장~7/2 사이에도 야간 시설 종료 시간이 22:00로 보인다.
3. **주간 시간은 첫 시설 기준** — 시설마다 주간 시간이 다르면 공통 표시가 틀린다.
4. **폐장 후에도 9/15까지 노출** — 이 기간에도 "휴무 없음"·초록 점이 그대로라 운영 중으로 오해할 수 있다. (결정 필요: 폐장 후 "시즌 종료" 표시 여부)
5. 부가 정보(사물함·파라솔·선베드·음식 규정)는 데이터만 있고 화면에 없다. 신뢰도 `low` 항목이 섞여 있어 노출 시 출처 표기 필요.
6. 피드백 폼의 수영장 목록에 한강 시설이 없다(성남 11곳만).
